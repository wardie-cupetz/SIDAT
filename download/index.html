📱 Cara Instalasi

  1. Tekan tombol DOWNLOAD SIDAT.
  2. Tunggu sampai file SIDAT.apk selesai diunduh.
  3. Buka file APK dari notifikasi download atau folder Download.
  4. Jika Android meminta izin, izinkan pemasangan aplikasi dari sumber tersebut.
  5. Tekan Instal, lalu buka aplikasi SIDAT.
Catatan: Android dapat menampilkan peringatan saat memasang APK di luar Google Play. Pastikan file berasal dari halaman resmi SIDAT.
